Bring your spreadsheet

If you already track spending in a spreadsheet, you should not have to type it all again. Export it as CSV, match up the columns, and this gives you back a ScripBook backup file you can import on your phone.

Your file never leaves this page. It is read in your browser and converted here. Nothing is uploaded, there is no server to upload it to, and you can turn off your connection before you start if you would rather prove it.

1. Your CSV

From Excel, Numbers, Google Sheets or anything else. File, then Export or Download as CSV.

Choose a CSV file or drag one here

2. What we found

3. Match the columns

Date and amount are required. The rest are optional.

4. Your ScripBook file

  1. Get the file onto your phone. AirDrop it, email it to yourself, or save it to Files or Drive.
  2. Open ScripBook, then Settings, then the Data tab.
  3. Tap Import and pick the file.
  4. Importing replaces what is already in the app, so export a backup first if you have entries you want to keep.
