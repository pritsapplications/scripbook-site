# ScripBook website

Marketing site for the ScripBook budgeting app.

`build.mjs` generates `index.html`. Edit the builder, not the output, then run:

```sh
node build.mjs
```

The app mark is drawn from the same cell geometry as `ScripBookApp/scripts/make-icons.mjs`,
so the site and the shipped icon cannot drift apart.

## Conventions

No em dashes anywhere in the copy.

The site is deliberately anonymous. No developer name appears on it.
