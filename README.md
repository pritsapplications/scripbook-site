# pritsapps.com

The Prits Apps studio site. Plain HTML generated by small Node scripts, served
by GitHub Pages. No framework, no dependencies, no build tooling beyond Node
and headless Chrome for the images.

```
./build.sh        # builds everything
```

## What it produces

| Path | Source | What it is |
| --- | --- | --- |
| `index.html` | `studio.mjs` | Studio home: who this is, the two apps, how they're built |
| `scripbook/index.html` | `build.mjs` | The ScripBook product page |
| `og.png` | `og.sh --studio` | Link preview card for the home |
| `scripbook/og.png` | `og.sh` | Link preview card for ScripBook |
| `favicon.ico`, `icon.svg`, `apple-touch-icon.png` | `favicon.sh` | Icons, from the app's S grid |
| `CNAME` | `build.sh` | `pritsapps.com` |

`src/` holds generated intermediates and is gitignored.

## How the pages work

Both use the same technique: full-viewport sections, each carrying a palette,
repainted as you scroll by an IntersectionObserver that sets CSS custom
properties on `:root`. Reveals fire once and stay revealed, because re-hiding
on the way back up reads as a bug. `prefers-reduced-motion` disables all of it.

The ScripBook page cycles the app's own sixteen palettes, which demonstrates
the theming feature rather than describing it. The studio home instead carries
each *app's* real palette in the section that introduces it: ScripBook's gold
on espresso, then Hit 50's paper and brick, which is light and lands as a
deliberate jolt after two dark screens.

## Marks

One 5x5 rounded-cell grid, two letters. The **S** is ScripBook's, geometry and
colours copied from `ScripBookApp/scripts/make-icons.mjs` so the icon and the
site cannot drift. The **P** is the studio's. Only the S carries the orange
accent cell.

## Copy rules

- No em dashes anywhere
- Contractions throughout, American spelling
- The app illustrations are hand-built CSS mock-ups and stay that way. They are
  not placeholders for screenshots.
- Nothing claims a studio-wide privacy promise the apps do not share. ScripBook
  keeps everything on device; Hit 50 is a public page with a database. The
  honest common ground is no ads, no trackers, nothing sold, and only the data
  an app needs to work.

## The two apps

- **ScripBook**, iOS and Android, not yet submitted. Source in the private
  `ScripBook` repo.
- **Hit 50 Before 30**, live at https://hit-50-before-30.vercel.app , Next.js
  on Vercel with a Neon Postgres database. Source in `hit-50-before-30`.

before anything is submitted, since moving it afterwards means updating two
